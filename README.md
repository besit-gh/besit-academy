# BESIT ACADEMY

**BESIT ACADEMY** — русскоязычная DevOps-RPG-академия: учебная кампания, проверяемые миссии и безопасные инфраструктурные симуляции.

## Требования

- Node.js 20+
- npm 10+

## Локальный запуск

```bash
npm ci
npm run dev
```

## Проверки

```bash
npm run typecheck
npm run test
npm run validate:content
npm run build
```

## Публикация

Проект предназначен для GitHub Pages и развёртывается workflow из `.github/workflows/deploy.yml`. Для репозитория `besit-academy` Vite использует базовый путь `/besit-academy/`.

В настройках репозитория откройте **Settings → Pages** и выберите **GitHub Actions** в качестве источника публикации.

## Принципы

- Учебный прогресс хранится локально в браузере; аккаунт не требуется.
- Подтверждение компетенции требует прохождения проверяемой практики.
- Терминал симулятора поддерживает только явно реализованные команды и не запускает системную оболочку.
- Реальные лаборатории выполняются в локальном окружении пользователя и не считаются пройденными автоматически.
- Клиентские сохранения можно редактировать; они не являются защищённой сертификацией.

## Статус

Репозиторий и продукт развиваются по вертикальным срезам. Статус публикации и проверок сообщается только после фактического выполнения.
